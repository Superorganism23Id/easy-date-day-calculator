# 쉬운 날짜·요일 계산기 프로젝트 제안서


## 1. 프로젝트 이름 : **쉬운 날짜·요일 계산기**  
### ***부제 : 쉽고 빠른 날짜/요일 계산 웹페이지***<br><br>


## 2. 한 문장 설명

 특정일을 기준으로 한 날짜, 요일, 기간 계산이 헷갈리는 사용자를 위해 이를 쉽고 빠르게 계산할 수 있는 Python 기반 날짜 계산 프로그램 웹페이지입니다.<br><br>


## 3. 만들려는 이유

생활 속에서 “며칠 전, 며칠 후가 무슨 요일인지”, “만료일까지 며칠 남았는지”, “두 날짜 간 기간이 정확히 며칠인지” 등을 확인해야 하는 경우가 자주 있습니다. 저와 주변 사람들도 이런 상황에서 직접 계산하다가 헷갈려서 인터넷 검색이나 AI에게 질문하는 경우가 많았습니다. 하지만 기존 웹페이지들은 기능이 각각 분리되어 있거나, AI는 기준날짜 포함 여부와 같이 기준을 일일이 입력하지 않으면 부정확한 답변을 하는 경우도 잦았습니다. 그래서 자주 쓰는 날짜 및 요일 계산 기능을 한곳에 모아 간단하고 직관적으로 사용할 수 있는 프로그램을 만들고자 합니다.<br><br>


## 4. 핵심 기능

### 기능 1: 오늘 기준 남은 일수 계산

사용자가 만료일 포함/미포함 여부를 선택하면, 오늘 날짜를 기준으로 특정 날짜까지 며칠 남았는지 계산합니다.(오늘도 포함해서 계산합니다.)

- 만료일 포함/미포함 여부를 선택 후 남은 일수 계산
- 예시: 오늘이 2026년 5월 14일이고 만료일이 2026년 5월 20일이면 남은 일수 출력<br>


### 기능 2: n일 뒤 또는 n일 전 날짜와 요일 계산

사용자가 숫자 `n`을 입력하고 전/후 여부를 선택하면, 오늘로부터 n일 후 또는 n일 전의 날짜와 요일을 계산합니다.

- n일 전/후 여부 선택 후 날짜 및 요일 계산
- 계산된 날짜와 요일 출력
- 예시: 오늘로부터 100일 뒤가 몇 월 며칠, 무슨 요일인지 출력<br>


### 기능 3: 입력 기간 일수 계산
사용자가 시작일과 끝일을 입력하고, 시작일/끝일 각각을 기간에 포함할지 선택한 후, 두 날짜 사이의 기간을 계산합니다.

- 시작일 포함 / 미포함 선택
- 끝일 포함 / 미포함 선택
- 전체 일수 출력
- 필요하면 대략적인 개월 수, 년 수로 변환하여 출력<br><br>



## 5. 예상 사용자

- 날짜와 요일, 기간 계산할 때마다 헷갈리는 나 자신
- 과제, 시험, 자격증, 신청 마감일 등을 확인해야 하는 학생
- 여행, 일정, 약속 날짜를 계산해야 하는 가족과 친구
- 만료일, 예약일, 기념일 등을 빠르게 확인하고 싶은 일반 사용자<br><br>

## 7. 사용할 Python 개념

| Python 개념 | 사용 계획 |
|---|---|
| 변수 | 입력 날짜, 계산 결과, 선택 옵션 저장 |
| 조건문 | 포함/미포함 선택, n일 전/뒤 선택 처리 |

| 리스트 | 요일 이름 저장 및 출력 |
| 문자열 처리 | 입력값 정리, 결과 문장 생성 |
| 예외 처리 | 잘못된 날짜 형식 입력 처리 |
