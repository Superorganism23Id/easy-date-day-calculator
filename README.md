# 프로젝트 이름

## 쉽고 빠른 날짜/요일 계산기
<br>

## 무엇을 하는 프로그램인가요?

이 프로그램은 사용자가 입력한 날짜를 기준으로, 날짜와 요일을 계산해 주는 Python GUI 프로그램입니다. 아래의 3가지 계산을 쉽고 빠르게 할 수 있습니다.

1. 기준일로부터 n일 전/후의 날짜 및 요일 계산
2. D-day 계산
3. 시작일과 끝일 간 기간 계산

<br>
<br>

## 실행 방법

1. Python 3.10 이상을 설치합니다.
2. Python IDLE이나 Python을 지원하는 IDE로 `date_weekday_cal.py`를 실행합니다.

<br>
<br>

## 사용된 Python 개념

- 리스트: 요일 이름 저장 후 결과 표시 등에 사용했습니다.
- 함수: 날짜 계산 기능과 GUI 이벤트 처리를 기능별로 분리했습니다.
- 모듈: `datetime` 모듈 안에서 `date`(날짜 클래스)와 `timedelta`(날짜 차이 클래스)를 import하여 날짜/요일 계산 기능을 구현했습니다. 또한 `tkinter` 모듈을 import하여 GUI 화면 구성, 입력창, 버튼, 체크버튼, 결과 출력창 등을 `Label`, `Entry`, `Button`, `Radiobutton`, `Checkbutton`, `Notebook` 등을 사용하여 구현했고, `command` 옵션으로 버튼 클릭 시 계산 함수가 실행되도록 했습니다.
- 조건문: n일 전/후 선택, 포함/제외 옵션, 입력 조건 확인 등에 사용했습니다.
- 예외 처리: 잘못된 날짜 입력, 숫자가 아닌 입력 등에서 발생하는 오류를 처리했습니다.

## 한계와 다음 단계

이 프로그램은 Python tkinter 기반 데스크톱 GUI 프로그램이므로 모바일 환경에서 사용이 불가합니다. 또한 데스크톱에서도 install 파일로 설치해서 사용하는 것이 아닌, 매번 `.py` 파일을 Python IDLE이나 IDE로 실행해야 합니다. 그리고 사용자가 수기로 날짜를 입력해야 하며, 외부 일정 관리 서비스(구글 캘린더, 삼성 캘린더 등)와 연동하여 원하는 일정을 자동으로 불러와서 계산하는 기능은 없습니다. 이 한계들을 해결하기에는 현재 제가 보유한 지식과 역량으로는 부족했습니다.

추후 웹 개발과 API 사용법을 추가로 학습하여, 이 프로그램을 웹사이트 형태로 배포하여 모바일 환경과 PC 환경 모두 손쉽게 사용이 가능하도록 만들고 싶습니다. 또한 구글 캘린더, 삼성 캘린더 등의 외부 일정 관리 서비스와 연동하여 원하는 일정을 자동으로 불러오는 기능을 추가하여, 더 빠르고 편리하게 날짜 및 요일 계산을 할 수 있도록 개선하고 싶습니다.
